### Краткое описание (показывается под названием)

> Конструктор мобильных приложений: создавайте интерфейс на React и собирайте APK прямо на телефоне или планшете

### Полное описание

```
NovaCompose Studio — конструктор мобильных приложений, работающий полностью на телефоне или планшете. Собирайте интерфейс из готовых компонентов, пишите логику на React, собирайте APK — компьютер не нужен.

Возможности:
— редактор кода в стиле VS Code: подсветка синтаксиса, автодополнение, вкладки файлов, проводник проекта;
— проверка кода на лету: ошибки и предупреждения видны прямо при наборе;
— живой предпросмотр экрана внутри конструктора;
— несколько экранов, состояние приложения (переменные), темы оформления;
— сборка Debug и Release APK на устройстве, установка результата через системный диалог Android;
— своя иконка и Application ID у собранных приложений — их можно публиковать в магазинах;
— русский и английский интерфейс, светлая и тёмная темы.

Как это работает: при первом запуске приложение устанавливает локальную среду сборки (Ubuntu, Node.js, Gradle, Android SDK) — нужен интернет и около 3 ГБ свободного места. Дальше проекты и сборка полностью на вашем устройстве.

Бесплатно, без встроенных покупок и подписок. Приложение поддерживается ненавязчивой рекламой Рекламной сети Яндекса. Работает на телефонах и планшетах с Android 7.0 и новее.
```

## 2. Обоснования чувствительных разрешений
(вставляется в блок «Чувствительные разрешения» в Консоли после загрузки AAB/APK)

### REQUEST_INSTALL_PACKAGES ⚠️ (ключевое)
```
NovaCompose Studio — это среда разработки (IDE): приложение локально собирает Android-проекты пользователя в APK-файлы. Разрешение используется исключительно для установки APK, собранных внутри самого приложения, и только по явной команде пользователя (кнопка «Установить» после завершения сборки). Установка выполняется через стандартный системный установщик пакетов Android с обязательным подтверждением пользователя.

Приложение НЕ загружает из сети и НЕ устанавливает сторонние приложения, НЕ является магазином приложений и НЕ обновляет само себя — это не обход механизма распространения RuStore, а основная функция инструмента разработки (аналогично другим опубликованным IDE).
```

### MANAGE_EXTERNAL_STORAGE
```
Доступ ко всем файлам необходим для работы встроенной среды сборки: инструментарий (Gradle, Android SDK, компилятор Kotlin) работает с файловой системой напрямую — читает и записывает произвольные файлы проектов пользователя (исходники, ресурсы, кеши сборки) и сохраняет результат (APK/AAB) во внешнее хранилище, например в «Загрузки» (/sdcard/Download), откуда пользователь может его открыть. Механизмы scoped storage/SAF для нативного инструментария сборки неприменимы.

Разрешение запрашивается один раз с пояснением; при отказе приложение продолжает работать (доступен редактор кода), недоступна только сборка. Файлы пользователя никуда не передаются — вся работа выполняется локально на устройстве.
```

### READ_MEDIA_IMAGES / READ_MEDIA_AUDIO / READ_MEDIA_VIDEO
```
На Android 13+ используются как базовый уровень доступа к файлам совместно с разрешением «Доступ ко всем файлам»: среда сборки читает файлы проектов и вложения (например, изображения-ресурсы, добавленные пользователем в проект). Медиатека не сканируется, данные не загружаются в сеть.
```

### READ_EXTERNAL_STORAGE / WRITE_EXTERNAL_STORAGE (Android ≤ 12.1)
```
Запрашиваются только на Android 12 и ниже (maxSdkVersion=32) для чтения файлов проектов и сохранения результатов сборки во внешнее хранилище — на этих версиях ОС нет scoped storage. На новых версиях не запрашиваются.
```

### POST_NOTIFICATIONS
```
Уведомления о ходе длительных операций: подготовка среды, установка компонентов и сборка проекта выполняются в фоновой службе (foreground service); уведомление показывает прогресс и позволяет вернуться в приложение. Рекламных уведомлений нет.
```

## 3. Комментарий для модераторов (поле при отправке версии)

```
Здравствуйте!

NovaCompose Studio — среда разработки Android-приложений, работающая полностью на устройстве (не веб-обёртка).

ВАЖНО: первая настройка требует интернета и 15–30 минут — приложение скачивает локальную среду сборки: образ Ubuntu arm64 (~300–500 МБ, наш релиз на GitHub: github.com/wfllive/rootfs), Node.js 24 (deb.nodesource.com), Gradle (github.com/gradle), Android SDK и зависимости при первой сборке (dl.google.com, repo.maven.apache.org). Все загрузки — по HTTPS, из открытых источников, версии зафиксированы. Это инструментарий сборки, а не обновление приложения: NovaCompose Studio не обновляет себя и не скачивает сторонние APK.

Сценарий проверки:
1. Откройте приложение → «Подготовка рабочей среды» → «Установить Ubuntu». Прогресс виден в уведомлении, дождитесь завершения.
2. На следующем экране нажмите «Установить RAI», дождитесь «Среда готова».
3. Создайте проект (кнопка «+») — откроется редактор кода; вкладка «Дизайн» показывает предпросмотр экрана.
4. Нажмите «Собрать» → «Debug APK». Сборка занимает 5–15 минут, ход — в уведомлении.
5. После сборки нажмите «Установить» — появится штатный системный диалог установки APK (для этого и нужно разрешение на установку пакетов).

При запросе «Доступ к файлам» (All files access) — разрешите: среде сборки нужно читать/писать файлы проектов. При отказе приложение не падает: редактор работает, недоступна только сборка.

Авторизации, тестового аккаунта, встроенных покупок нет. Персональные данные разработчиком не собираются. В приложении есть реклама Рекламной сети Яндекса: баннер внизу списка проектов и полноэкранный блок после успешной сборки (не чаще одного раза в 5 минут, не после каждого действия) — используются официальный SDK yandex-mobile-ads и демо/боевые блоки РСЯ. По любым вопросам: [ваш email] — отвечу и помогу воспроизвести.

Про устройство приложения: это не обёртка сайта. WebView-компоненты используются только с локальным контентом: редактор кода встроен в приложение и работает офлайн, предпросмотр экрана обслуживается локальным сервером на 127.0.0.1 на самом устройстве (поэтому в манифесте разрешён cleartext-трафик к localhost — внешние ресурсы по HTTP не загружаются). OTA-обновлений JS в обход RuStore нет (expo-updates отключён).
```

## 5. Чек-лист перед загрузкой версии

- [ ] Сборка `eas build -p android --profile production` (AAB, без dev-client)
- [ ] Проверить разрешения в финальном файле: `aapt dump badging app.aab | grep permission` (для AAB — через `bundletool build-apks`): в списке должны быть только задекларированные разрешения; `SYSTEM_ALERT_WINDOW` отсутствует ✅ (убран из релизного манифеста)
- [ ] В релизной сборке нет dev-меню/expo-dev-client (проверить установку APK на чистом устройстве)
- [ ] OTA-обновления JS отключены ✅ (`expo.modules.updates.ENABLED=false` в манифесте) — правило «обновления только через RuStore» соблюдено
- [ ] Название на витрине = названию в приложении (NovaCompose Studio = `app_name`) ✅
- [ ] Иконка на витрине = иконке приложения (`assets/icon.png`) ✅
- [ ] Скриншоты 9:16, русский язык, без статус-бара и UI других приложений
- [ ] Тест: отказать во всех разрешениях → приложение не падает, редактор работает
- [ ] Тест на чистом устройстве: полный цикл «установка Ubuntu → RAI → проект → сборка → установка APK» без зависаний
- [ ] Описание без кликбейта («лучший», «единственный»), без слова «официальный» ✅ (черновик выше)
- [ ] Ссылка на политику конфиденциальности опубликована и открывается
- [ ] При первом запуске показывается экран политики конфиденциальности с кнопкой согласия ✅ (реализовано в приложении, ключ `@nova_privacy_accepted_v1`)
- [ ] Заполнена анкета возрастного рейтинга (отметить «в приложении есть реклама», если спросят)
- [ ] В разделе «Безопасность / пользовательские данные» Консоли указать: рекламный идентификатор устройства (AD_ID) — используется Яндексом для показа рекламы
- [ ] В `src/ads/adsConfig.ts` заменены демо-блоки (`demo-banner-yandex`, `demo-interstitial-yandex`) на свои из partner.yandex.ru — демо-блоки дохода не дают
- [ ] Версия на RuStore не ниже версий в других сторах (при выкладке параллельно)

## 6. Если публикуете приложение, собранное в конструкторе

Шаблон проекта: React (Vite) + нативная WebView-обёртка, которая показывает **локальный** `dist` из assets — раздача идёт через `WebViewAssetLoader` (хост `https://appassets.androidplatform.net`, стандартное решение от androidx.webkit; так ES-модули работают без опасных file://-флагов). Для RuStore это допустимо: запрет п. 1 касается приложений-обёрток, чья единственная цель — перенаправление на внешний сайт. Локальный интерфейс в WebView — рабочая схема (так устроены Cordova/Capacitor-приложения).

Обязательно перед публикацией собранного приложения:

1. **Смените имя пакета** в Настройках проекта: по умолчанию `com.rnstudio.<slug>` — укажите свой (например, `ru.<вашеимя>.<приложение>`). Имя пакета после первой загрузки в RuStore изменить нельзя.
2. **Иконка**: по умолчанию генерируется автоматически (фон — primary цвет темы). Чтобы поставить свою: положите квадратный PNG (≥432×432) в общее хранилище (например, `/sdcard/Download/icon.png`), укажите путь в Настройках проекта → поле «Иконка PNG» и заново выполните «Подготовить проект». Края (~17 %) попадут под маску адаптивной иконки — логотип держите по центру. Для витрины загрузите PNG 512×512 с тем же дизайном.
3. **Диапазон Android 7–17**: по умолчанию minSdk = 24 (Android 7), targetSdk = 37. На API 24–25 используется обычная иконка, а Android 8+ автоматически выбирает адаптивный ресурс `drawable-anydpi-v26`.
4. **Не грузите в WebView внешний сайт** как единственный контент — это отказ по п. 1 («привлечение трафика на сайт»). Сетевые запросы к API — можно, интерфейс должен жить локально; только HTTPS (в шаблоне cleartext не разрешён).
5. **Разрешения по умолчанию** — только `INTERNET` и `ACCESS_NETWORK_STATE` (категория «безопасные»), декларировать нечего. Если добавите в шаблон свои разрешения — каждое надо будет обосновать в Консоли.
6. В комментарии модератору можно указать: «Интерфейс приложения — локальный веб-бандл в WebView (работает офлайн), сборка выполнена конструктором NovaCompose Studio».
7. Версию повышайте `versionCode` при каждом обновлении (Настройки проекта) и не теряйте `keystore.properties` — обновления принимаются только с той же подписью.
