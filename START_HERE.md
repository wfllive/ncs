# Начало работы с Compose Studio

**Сначала прочитайте [`docs/ИНСТРУКЦИЯ.md`](docs/ИНСТРУКЦИЯ.md)** — там по шагам:
как собрать APK конструктора на компьютере, что происходит при первом запуске
на телефоне, как создать и собрать первое приложение, как обновить RAI.

Кратко:

1. Соберите и установите development build самого конструктора
   (`npm install && npx expo run:android`, или `npm run bd` — EAS).
2. При первом запуске установите Ubuntu arm64 (скачивание идёт в фоне).
3. После Ubuntu приложение откроет страницу **«Установка RAI»**: apt → Node.js →
   локальный бандл RAI (вендорен в `rai/`, внутри APK) → `rai install base` →
   `rai install sdk` → `rai status`. GitHub не нужен. Установку можно свернуть —
   она продолжается в фоне.
4. После успешного `rai status` откроется список проектов.
5. Создайте проект и укажите имя приложения и Application ID.
6. Во вкладке «Редактор» пишите Kotlin-код файла — это исходный код, который сохраняется на диск как есть.
7. Слева — панель «Файлы проекта»: откройте любой файл проекта (экраны, тему, Gradle, манифест) и редактируйте его.
8. Нажмите «Сохранить», чтобы записать изменения в proot.
9. Во вкладке «Дизайн» проверьте предпросмотр активного экрана, отрисовываемый из кода.
10. Откройте «Gradle Build» и выполните `assembleDebug`. Сборка тоже работает в фоне.
11. Установите полученный APK для настоящего нативного предпросмотра.

Сгенерированные проекты находятся в `/root/compose-projects/` внутри Ubuntu.
