# Начало работы с NovaJava Studio

**Сначала прочитайте [`docs/Instruks.md`](docs/Instruks.md)** — там по шагам:
как собрать APK конструктора на компьютере, что происходит при первом запуске
на телефоне, как создать и собрать первое приложение, как обновить RAI.

Кратко:

1. Соберите и установите development build самого конструктора
   (`npm install && npx expo run:android`, или `npm run bd` — EAS).
2. При первом запуске установите Ubuntu arm64 (скачивание идёт в фоне).
3. Приложение откроет страницу **«Установка среды»** (ускоренный профиль,
   без RAI): `apt update` → JDK 17 + python3 + утилиты → **Storm Build**
   (бандл из APK, офлайн) → `storm setup` (aapt2, android.jar, R8) →
   проверка окружения.
   Установку можно свернуть — она продолжится в фоне с того же шага.
4. После успешного `rai status` откроется список проектов.
5. Создайте проект (имя + Application ID) — файлы **Java + XML** пишутся
   мгновенно, без скачиваний.
6. Во вкладке «Редактор» правьте `app/res/layout/*.xml` (макет) и
   `app/src/**/…Activity.java` (код) — на диск пишется как есть.
7. Вкладка **«Дизайн / Превью»** — горячий предпросмотр макета: сохраняется
   при каждом сохранении файла (и при автосохранении — при наборе).
8. Экран **«Сборка»** → «Запустить»: кастомный сборщик **Storm Build**
   (без Gradle: `aapt2 → javac → d8/R8 → zipalign → apksigner`) собирает
   APK за секунды, проверяет его и копирует в `Загрузки/NovaJava/<проект>/apk`.
   Там же — Release, AAB и создание ключа подписи.
9. «Установить APK» — установка и запуск собранного приложения.

Сгенерированные проекты находятся в `/root/projects/` внутри Ubuntu.
