# NovaJava Studio — конструктор нативных Android-приложений (Java + XML)

NovaJava Studio создаёт **нативные Android-проекты на чистом Java + XML** и
собирает их **кастомным пайплайном без Gradle** — прямо на телефоне, в
окружении Ubuntu (proot). Сам конструктор работает как Android-приложение.

> 📖 Пошаговая инструкция: [`docs/Instruks.md`](docs/Instruks.md).

## Что изменилось (редизайн)

| Раньше | Теперь |
| --- | --- |
| Проекты на Kotlin/Compose или React + Vite + WebView | **Java + XML** (классический Android) |
| Сборка через Gradle (минуты, даемоны, зависимости) | **Кастомный сборщик [Storm Build](https://github.com/wfllive/Storm-Build)**: `aapt2 → javac → d8/R8 → zipalign → apksigner`, APK + AAB, Maven-зависимости (секунды) |
| Предпросмотр через Vite-сервер | **Встроенный рендер макета** — мгновенный **hot reload** без сервера и эмулятора |
| Установка среды: `apt upgrade` + Node.js + … | Быстрый профиль: `apt update` + JDK 17 + SDK, **без Node.js** |
| Создание проекта: `npm install` (минуты) | Мгновенная запись файлов шаблона |

## Возможности

- создание полноценного проекта **Java + XML**: манифест, активности,
  макеты, ресурсы, векторные/адаптивные иконки, тема;
- **код — источник истины**: правите `src/**/*.java` и `res/layout/*.xml`
  в редакторе — на диск пишется как есть, ничего не перегенерируется;
- **кастомная сборка без Gradle — Storm Build** (вендорен в `storm/`, зашит
  в APK, работает офлайн): каждая задача — `bash build.sh …`, внутри
  `storm build apk|aab`; debug/release/aab/keystore/clean, подпись, экспорт в
  `Загрузки/NovaJava/<проект>/apk`, установка и запуск на устройстве;
- **библиотеки**: подключение Maven-зависимых (androidx, material, okhttp,
  Yandex Ads…) через `storm deps add` — экран «Пакеты»;
- **горячий предпросмотр (hot reload)**: макет рендерится встроенным
  движком (`src/utils/layoutPreview*`) в WebView — обновляется при каждом
  сохранении/наборе, понимает `@string/@color/@dimen`, dp/sp, веса,
  гравитацию и основные виджеты платформы;
- редактор кода на CodeMirror 6 (офлайн, как в настольной версии): темы
  VS Code Dark+/Light+, подсветка **Java и XML**, автодополнение
  (ключевые слова, Android-сниппеты, виджеты и атрибуты), поиск/замена,
  переход к строке, сворачивание, вкладки, хлебные крошки, статус-строка;
- живая проверка макетов (разбор XML с номерами строк) и быстрая проверка
  проекта (макеты + синтаксис `build.sh`) одной кнопкой;
- проводник файлов проекта, несколько экранов (экран = активность + макет),
  светлая/тёмная тема, русский и английский язык.

## Сгенерированный проект

```text
/root/projects/my-app/
├── storm.m                 # манифест проекта для Storm
├── project.json            # метаданные (пакет, версии, SDK)
├── build.sh                # обёртка над `storm build …`
├── app/
│   ├── AndroidManifest.xml
│   ├── src/com/example/app/…   # Activity по одной на экран
│   ├── res/layout/…            # XML-макеты
│   ├── res/values/…            # строки, цвета, темы
│   └── proguard-rules.pro
└── build/outputs/          # готовые APK/AAB
```

Команды проекта:

```bash
bash build.sh            # debug APK (быстро)
bash build.sh release    # release APK (R8 + подпись; сначала ключ)
bash build.sh aab        # AAB для Google Play / RuStore
bash build.sh keystore   # создать release-ключ
bash build.sh clean      # очистка артефактов
storm deps add <g:a:v>   # Maven-зависимость (или экран «Пакеты»)
```

## Первый запуск: Ubuntu → среда → проекты

1. **Установка Ubuntu** — скачивание и распаковка arm64-образа (можно
   свернуть — фоновая служба продолжит).
2. **Установка среды** (ускоренный профиль, без RAI и без Gradle):
   `apt update` → JDK 17 + python3 + утилиты → **Storm Build** (бандл из APK
   → `/root/storm`, офлайн) → `storm setup --api 34` (сам скачивает aapt2,
   `android.jar`, `r8.jar`, `bundletool.jar`) → проверка окружения.
   Каждый шаг идемпотентен. Если уже стоит старый SDK (`~/android-sdk`),
   Storm использует его — повторных скачиваний нет.
3. После проверки среды открывается список проектов. Создавайте проект —
   файлы пишутся мгновенно, без скачиваний.

## Предпросмотр и «живой» цикл

- вкладка **«Дизайн / Превью»** рендерит активный макет из текущего кода:
  сохранили (или просто набирать текст при включённом автосохранении) —
  превью перерисовалось. Это и есть hot reload макетов;
- экран **«Горячий предпросмотр»** следит за файлом макета и обновляется
  сам, плюс кнопка **«Собрать и установить»** — полный цикл на устройстве;
- экран **«Сборка»** — кастомный пайплайн с живым терминалом, проверкой
  артефакта (aapt2), экспортом и установкой.

## Технологии

- конструктор: React Native (Expo SDK 57), CodeMirror 6, proot Ubuntu arm64;
- сборщик: **Storm Build 2026** (вендорен в `storm/`; Python stdlib,
  понимает `ANDROID_HOME`, при необходимости добирает `android.jar`);
- сгенерированные приложения: чистый `android.*` по умолчанию (+ опциональные
  Maven-библиотеки), `minSdk 24 / targetSdk 34`, JDK 17;
- сборка конструктора: `npm install && npx expo run:android` (или EAS).

## Полезные команды (корень репозитория)

```bash
npm test            # тесты: генератор проектов, сборщик, предпросмотр
npm run test:ide    # тесты редактора и анализатора
npm run editor      # пересборка редактора (после правок в web/)
npm run bd          # EAS development-сборка конструктора
```
